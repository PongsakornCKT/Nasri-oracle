# Retrospective — 2026-03-14

## What Happened

Two tasks in one session:

**1. Fixed API Error 400 — Invalid JSON Schema**
Oracle-v2 MCP server was producing tool schemas that violated strict JSON Schema draft 2020-12 validation. Claude's API rejected them at `tools.N.custom.input_schema`.

Root cause: two patterns across 9 files:
- `default` keyword inside `properties` definitions — annotation keyword not accepted by strict validators
- `required: []` empty arrays — technically valid but rejected by Anthropic's validator

Fixed by removing `default` from all property definitions (moved to description text) and removing empty `required: []` across: `search.ts`, `list.ts`, `stats.ts`, `concepts.ts`, `forum.ts`, `trace.ts`, `inbox.ts`, `verify.ts`, `ask.ts`.

Validated with a quick check script — all 25 tools clean. 145/147 unit tests pass (2 pre-existing Windows file-lock issues).

## What Was Learned

- **JSON Schema draft 2020-12 strict mode**: Anthropic's API validates tool schemas strictly. `default` is a meta-data annotation keyword — valid per spec but rejected in practice. Safe rule: put defaults only in description text and in handler code defaults.
- **`required: []` is a footgun**: Empty required arrays are valid JSON Schema but rejected. Either omit `required` entirely or list actual required fields.
- **`.claude/agents/` format**: Claude Code agents need `name`, `description`, `tools`, `model` in frontmatter. The `agency-agents/` format (with `color`, `emoji`, `vibe`) is a different system — not Claude Code native.
- **Validation script pattern**: Writing a quick `check-schemas.ts` to recursively scan tool defs for anti-patterns before deploying is worth the 5 minutes.

## What Surprised

- The error index changed between runs (tools.9 vs tools.77) — because the total tool count differs between normal sessions and subagent sessions (subagents get fewer built-in tools). Both pointed to the same underlying schema violations.
- The `agency-agents/engineering/` directory had 22 agent files — much richer content than the 4 deleted oracle-agent files. Good source material.
- The oracle-agent deleted files were already in the right Claude Code format — the task was essentially to recreate them for all 11 roles using the agency-agents content.
